# ✈️ AERIS | Aviation World

AERIS is a modern, responsive aviation website designed to showcase the fascinating world of flight, aircraft, and aviation technology.

The website features a dark navy theme, blue accents, smooth animations, and an interactive layout.

## 🌐 Features

- Fully responsive design
- Modern navigation bar with a mobile menu
- Animated homepage
- Aircraft category cards with hover effects
- Aviation technology section
- Aircraft specifications
- Interactive image gallery
- Smooth scrolling and CSS animations
- Contact section

## 🛩️ Website Sections

1. **Home** – Introduction to AERIS and the world of aviation.
2. **About** – Aviation history, innovation, and engineering.
3. **Aircraft** – Passenger, fighter, and cargo aircraft.
4. **Technology** – Jet engines, flight systems, and aerodynamics.
5. **Specifications** – Technical information about legendary aircraft.
6. **Gallery** – A collection of aviation photographs.
7. **Contact** – Contact information and website footer.

## 💻 Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Animations
- Responsive Web Design

The website is built using HTML and CSS without JavaScript frameworks.

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Explore the AERIS website!
